# LIBENS IconChanger

Windows 10/11 x64용입니다. `LIBENS IconChanger.exe`를 실행하세요.

GitHub Releases의 `LIBENS-IconChanger-1.4.1-win-x64.zip` 하나를 내려받고, 마우스 오른쪽 버튼의 `모두 압축 풀기`로 전체를 푸세요. 압축을 푼 폴더에서 `essential`을 열고 EXE를 더블 클릭하면 됩니다. ZIP 안에서 바로 실행하지 마세요. 별도 설치·소스 빌드가 필요하지 않습니다.

이 essential 폴더 전체가 실행 단위입니다. 폴더를 통째로 복사하면 .NET을 별도 설치하지 않고 실행할 수 있습니다. EXE만 따로 옮기지 마세요.

이름 변경 후에도 기존 백업과 적용 ICO를 계속 사용하도록 데이터 폴더 이름은 `FileIconManager`를 유지합니다.

오른쪽 위 `KO / EN` 메뉴에서 한국어 또는 English를 선택합니다. Windows 표시 언어가 한국어이면 한국어로, 그 외에는 영어로 시작합니다. `--lang ko` 또는 `--lang en` 인수로 시작 언어를 지정할 수도 있습니다. 언어 전환 시 입력값은 유지하며 관리자 재실행에도 선택 언어를 전달합니다. 언어 선택은 이번 실행에 적용됩니다. 영어 안내는 `USER-GUIDE.en.md`에 있습니다.

1. '파일 확장자'에서 확장자를 입력하거나, 'Windows 기본 아이콘'에서 변경할 대상을 선택하세요.
2. 사용할 이미지 또는 아이콘 파일을 선택하세요.
3. 꽉 찬 이미지의 모서리를 둥글게 만들려면 `모서리 둥글기`를 1~50%로 지정하세요. 0은 원본 유지입니다.
4. 미리보기를 확인하고 아이콘 적용을 누르세요.
5. Windows 기본 아이콘은 안내에 따라 캐시를 갱신하고 탐색기를 다시 시작해야 현재 창에 반영됩니다.
6. 원래대로 되돌리려면 목록에서 항목을 선택하고 선택 항목 복원을 누르세요.

- 화면에 표시된 PNG, JPG/JPEG, GIF, BMP, TIFF, WEBP, SVG, ICO, EXE, DLL을 지원합니다. WEBP·SVG 등은 Windows의 이미지/썸네일 지원 환경에 따라 읽습니다.
- Windows 기본 아이콘 목록은 각 항목 왼쪽에 32px 보통 크기 미리보기를 표시합니다. 폴더·드라이브 등 stock 항목은 현재 Windows 셸 아이콘을, 내 PC·휴지통 등은 해당 기본 시스템 리소스를 읽습니다.
- 모서리 둥글기는 네 모서리가 불투명한 정사각형·직사각형에만 적용합니다. 투명 모서리가 감지된 PNG/ICO 등은 이미 가공된 아이콘으로 보고 다시 자르지 않습니다.
- 같은 파일 형식 연결(ProgID)을 공유하는 확장자는 함께 바뀔 수 있습니다.
- 일반 확장자와 내 PC·휴지통·네트워크·사용자 파일 아이콘은 현재 사용자 범위입니다.
- 기본 폴더·바로가기 화살표 오버레이·기본 문서·드라이브·프린터 및 EXE 대체 아이콘은 전체 사용자 범위입니다. '관리자 모드 열기'를 직접 눌러 승인한 새 창에서 적용/복원하세요. 새 관리자 창이 시작되면 기존 일반 권한 창은 자동으로 닫힙니다. UAC를 취소하거나 실행에 실패하면 기존 창은 유지됩니다. 다른 관리자 계정으로 인증하면 현재 사용자 설정은 그 계정에 적용됩니다.
- 변경 백업과 자동 변환 ICO는 해당 PC의 %LOCALAPPDATA%\FileIconManager에 보관합니다. 다른 PC로 앱을 복사해도 이전 PC의 설정과 백업이 자동 이전되지는 않습니다.
- 전체 사용자 설정의 백업과 ICO는 %PROGRAMDATA%\FileIconManager에 보관합니다. 이 폴더를 삭제하면 복원이 어렵거나 아이콘이 사라질 수 있습니다.
- 이번 버전부터 ICO/EXE/DLL도 보관용 ICO를 만들므로 새 적용분은 원본 이동·삭제의 영향을 받지 않습니다. 예전 버전으로 적용한 직접 참조 아이콘은 예외입니다.
- assets는 앱 아이콘 리소스, source는 현재 소스 코드입니다. 주변 DLL과 런타임 파일은 실행에 필요합니다.
- 다른 PC의 Windows 권한, 보안 정책 또는 썸네일 공급자에 따라 사용 가능한 기능이 달라질 수 있습니다.

## EXE의 기존 아이콘 유지

.exe를 입력하면 '자체 아이콘이 없는 EXE에만 적용' 옵션이 나타납니다. 기본으로 선택되어 있습니다.

- 선택: 프로그램 자체 아이콘을 유지하고 기본 대체 아이콘만 변경합니다. 전체 사용자 범위이며 관리자 권한이 필요합니다. 현재 사용자의 EXE 기본 참조는 %1(파일 자체)로 설정합니다.
- 해제: 현재 사용자의 EXE 아이콘을 일괄 지정합니다. EXE 내부 데이터와 실행 명령은 바꾸지 않습니다.
- 체크 상태만 바꾸어서는 설정이 바뀌지 않습니다. 반드시 '아이콘 적용'을 누르세요.
- 이전에 적용한 전체 사용자 대체 아이콘은 체크를 해제한 뒤에도 남습니다. 완전히 되돌릴 때는 변경 기록의 EXE 묶음을 관리자 모드에서 복원하세요.
- 다른 아이콘 처리기·비표준 EXE 연결이 있으면 안전을 위해 중단합니다. 캐시 손상으로 흰 아이콘이 보이는 문제를 복구하는 옵션은 아닙니다.

## 적용 범위와 복원

- 기본 폴더는 `닫힘+열림 모두`, `닫힘만`, `열림만`에서 고릅니다. 같은 계열의 최초 값은 복원 시 함께 묶일 수 있습니다. 내용 썸네일, 개별 설정 폴더, 특수 폴더는 다른 아이콘을 유지할 수 있습니다.
- 휴지통은 `두 상태 모두`, `비어 있음`, `가득 참`에서 고릅니다. 개별 상태를 고르면 반대 상태는 보존하고 현재 표시값도 상태에 맞춥니다. 복원은 휴지통 두 상태를 함께 되돌립니다.
- 네트워크 드라이브는 `두 상태 모두`, `연결됨만`, `연결 끊김만`에서 고를 수 있습니다.
- `바로가기 화살표 오버레이`는 Windows의 모든 바로가기에 공통으로 겹치는 그림입니다. 투명 배경 이미지를 권장하며, 개별 바로가기의 아이콘·대상과 바로가기 기능은 바꾸지 않습니다. 개별 바로가기용 별도 적용·백업 옵션은 없습니다.
- `바로가기 화살표 오버레이`를 선택하면 `오버레이 크기`가 활성화됩니다. 10~100%에서 조절하며 기본값 50%는 이미지 가로·세로 길이를 각각 절반으로 줄여 좌측 하단에 배치합니다. 전체 캔버스 크기는 유지하고 나머지는 투명하게 저장하므로 원본 파일의 픽셀 해상도만 줄이는 것과 다릅니다.
- `아이콘 번호`는 원본 파일로 EXE 또는 DLL을 선택했을 때만 표시됩니다. 변경 대상 확장자가 `.exe`라는 이유만으로는 표시되지 않습니다. `오버레이 크기`는 Windows 기본 아이콘에서 `바로가기 화살표 오버레이`를 선택했을 때만 표시됩니다. 두 조건을 모두 만족하면 두 옵션이 함께 나타납니다.
- 오버레이 축소·투명 여백은 미리보기와 보관용 다중 해상도 ICO에 똑같이 적용됩니다. 적용 완료 후에는 원본 이미지를 삭제해도 되지만 `%PROGRAMDATA%\FileIconManager\generated-icons`의 보관 ICO는 삭제하지 마세요.
- 드라이브·프린터 등의 기본 아이콘 변경이 모든 설정 앱·제조사 아이콘에 적용되는 것은 아닙니다.
- Windows 기본 아이콘 적용·복원 후에는 캐시 갱신·탐색기 재시작 확인 창이 열립니다. 동의한 경우에만 자동 생성된 iconcache/thumbcache 파일을 지우고 Windows 셸을 다시 시작합니다. 실제 문서·사진은 삭제하지 않지만 폴더 창과 작업 표시줄이 잠시 닫히므로 진행 중인 파일 작업을 먼저 끝내세요.
- 확인 창을 취소했다면 화면 아래 `캐시 갱신 · 탐색기 재시작` 버튼을 나중에 눌러도 됩니다. 그래도 표시가 바뀌지 않으면 로그아웃 후 다시 로그인하세요.
- 1.1.2부터 시스템 이미지 목록과 바탕 화면 항목에도 별도의 갱신 이벤트를 보냅니다. 폴더 바로가기는 대상 폴더 그림 위에 현재 Windows 전역 바로가기 오버레이를 합성합니다.
- 실제 폴더에 문서·사진 등 내용 미리보기가 표시되는 경우에는 기본 폴더 아이콘과 별도입니다. 기본 아이콘 변경은 미리보기 생성 기능을 끄거나 폴더별 아이콘을 강제로 지정하지 않습니다.
- 같은 대상의 최초 원본 백업은 반복 적용해도 하나만 유지합니다. 서로 다른 대상의 백업과 서로 다른 보관용 ICO는 늘어날 수 있으며 ICO 자동 정리는 하지 않습니다.
- 백업이 손상되면 해당 범위의 쓰기를 차단하고 원본을 보존합니다. 백업 파일을 임의로 비우지 말고 먼저 별도로 보관하세요.
