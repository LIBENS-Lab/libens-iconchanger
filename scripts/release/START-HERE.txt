English
1. Right-click the ZIP and select "Extract All".
2. Open the essential folder inside the extracted folder.
3. Double-click LIBENS IconChanger.exe.

No installer, separate .NET installation, or source build is required.
Extract all files first; do not run the app from inside the ZIP.
Keep the entire essential folder together, not just the EXE.
Choose Korean or English with KO / EN in the app.
More help: essential/USER-GUIDE.en.md

This app is not code-signed. Windows may display a security warning.
Only use downloads from https://github.com/LIBENS-Lab/libens-iconchanger/releases
Do not disable Windows security protections to run it.

Backups and stored icons remain on the PC where changes are applied.
Keep %LOCALAPPDATA%/FileIconManager and %PROGRAMDATA%/FileIconManager.
