# LIBENS IconChanger 1.4.1

## 한국어 — 다운로드 및 실행

1. 아래 Assets에서 **LIBENS-IconChanger-1.4.1-win-x64.zip** 하나를 내려받으세요. `Source code`는 개발자용이며 실행 파일이 없습니다.
2. ZIP을 마우스 오른쪽 버튼으로 눌러 **모두 압축 풀기**를 선택하세요.
3. 압축을 푼 폴더에서 `essential`을 열고 **LIBENS IconChanger.exe**를 더블 클릭하세요.

별도 설치·.NET 설치·소스 빌드가 필요하지 않습니다. 주변 DLL·assets·licenses가 필요하므로 EXE만 따로 옮기지 말고 `essential` 전체를 함께 보관하세요. Windows x64용이며 x86·ARM64 네이티브·macOS·Linux 배포본은 제공하지 않습니다. 앱 오른쪽 위 `KO / EN` 메뉴에서 한국어·영어를 선택합니다.

## English — download and run

1. Download **LIBENS-IconChanger-1.4.1-win-x64.zip** from Assets below. The automatically generated `Source code` downloads are for developers and do not contain a runnable app.
2. Right-click the ZIP and choose **Extract All**.
3. Open `essential` in the extracted folder and double-click **LIBENS IconChanger.exe**.

No installer, separate .NET installation, or source build is required. Keep the whole `essential` folder together, including the adjacent DLLs, assets and licenses. This is a Windows x64 build; native x86/ARM64, macOS and Linux packages are not provided. Select Korean or English using `KO / EN` in the app.

## Included and known limitations

1. File-type and Windows system-icon changes, original-setting backup/restore, image-to-ICO conversion, corner rounding and shortcut-overlay scaling.
2. Bundled .NET and Windows Desktop runtime **10.0.13**, MIT license, runtime notices and both user guides.
3. The app is **not code-signed**. Windows may display a security warning. Download only from this repository; do not disable Windows security protections.
4. System-wide changes require administrator permission. Explorer refresh/restart happens only after confirmation; finish file operations first.
5. Custom folder icons, content thumbnails and some Windows views can retain their own appearance. WEBP/SVG support depends on the installed Windows image/thumbnail providers.
6. Backups and stored ICO files remain in `%LOCALAPPDATA%\FileIconManager` and `%PROGRAMDATA%\FileIconManager`; copying the app does not move these settings to another PC.
7. `SHA256SUMS.txt` is optional for verifying the ZIP. Only the ZIP is needed to use the app.

See [the changelog](https://github.com/LIBENS-Lab/libens-iconchanger/blob/v1.4.1/CHANGELOG.md) and the bundled user guides for details.
