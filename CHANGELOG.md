# Changelog

## 1.4.1 — 2026-10-14

1. Unified project folder, project file and executable names as `LIBENS IconChanger`.
2. Updated build scripts, shortcut paths and portable checks for paths containing spaces.
3. Retained earlier backup and stored-icon paths for compatibility.

## 1.4.0 — 2026-10-14

1. Added LIBENS branding and English UI with Korean/English switching.
2. Localized app labels, tooltips, system-icon descriptions and confirmation/error messages.
3. Preserved entered paths and values while switching language; administrator launch carries the selected language.

## Earlier versions

1. Added file-type and Windows system-icon changes with original-setting backup and restore.
2. Added state selection for folders, Recycle Bin and network drives.
3. Added corner rounding and transparent-canvas scaling for the shared shortcut-arrow overlay.
4. Added administrator relaunch, icon-cache refresh and self-contained Windows x64 builds.
